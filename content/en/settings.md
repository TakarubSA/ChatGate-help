**Settings** is split into tabs. You only see the tabs your role can use.

## For you

| Tab | What you set |
| --- | --- |
| My profile | Name, photo (also shown in the top bar), mobile number, job title |
| Notifications | Pop-ups for new messages, sounds (listen to each one), alerts in the bell |
| Security | Your password and two-factor authentication |
| Updates & feedback | What's new, and sending us feedback |

## For the workspace

| Tab | What you set |
| --- | --- |
| General | Business details, time zone, working hours and holidays |
| WhatsApp connection | Numbers, registration with Meta, partner (BSP) key — see [Connect WhatsApp](/en/connect-whatsapp/) |
| Deployment & widget | The chat widget for your website |
| Balance & usage | This month's usage at a glance |
| Opt-out & opt-in | The replies customers get when they stop or restart promotions |
| Tags | The tags agents apply to conversations |
| Quick replies | Ready answers, in categories, inserted with <kbd>/</kbd> |
| Queues | Waiting queues for busy times |
| FAQ | Questions every bot answers |
| Voice AI | Transcribe voice notes so bots can understand them |
| API keys | Keys for your systems |
| Audit Log | A read-only record of important settings changes |

## Opt-out and opt-in

Customers control **marketing** messages themselves; service messages aren't affected.

- A customer stops promotions by tapping **Stop promotions** on a template or by writing a stop word. They get your opt-out reply and are skipped by marketing campaigns from then on.
- They restart by writing words like *start*, *subscribe*, *اشتراك* or *تفعيل* (or tapping **Accept promotions**), and get your opt-in reply.

Write several replies and mark the active one (shown in green).

## Voice AI

Turn it on to transcribe WhatsApp voice notes automatically and understand them with AI, so the bot can answer as if the customer had typed. You can use your own AI provider key.

## Logs

**Logs** records what happened in the workspace:

| Log | Shows |
| --- | --- |
| Activity | Sign-ins, security and cross-workspace access |
| Agent activity | Assigning, replying, closing and agents joining or leaving conversations |
| Custom events | Events fired by the *Trigger event* node in bots |
| Retries | Campaign resend attempts, automatic or manual |
| API | Every call through integrations, with sensitive data masked |
| Admin actions | Plan changes, top-up approvals and other administrator actions on your account |
