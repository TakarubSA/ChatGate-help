**الإعدادات** مقسّمة إلى تبويبات، ولا تظهر لك إلا التبويبات التي يستخدمها دورك.

## لك أنت

| التبويب | ما تضبطه |
| --- | --- |
| ملفي الشخصي | الاسم، والصورة (تظهر أيضًا أعلى الصفحة)، ورقم الجوال، والمسمى الوظيفي |
| التنبيهات | بطاقات الرسائل الجديدة، والأصوات (مع الاستماع لكل نغمة)، وتنبيهات الجرس |
| الأمان | كلمة المرور والتحقق بخطوتين |
| التحديثات والملاحظات | ما الجديد، وإرسال ملاحظاتك لنا |

## لمساحة العمل

| التبويب | ما تضبطه |
| --- | --- |
| عامة | بيانات النشاط، والمنطقة الزمنية، وساعات العمل والإجازات |
| اتصال واتساب | الأرقام، والتسجيل لدى Meta، ومفتاح الشريك (BSP) — راجع [ربط واتساب](/ar/connect-whatsapp/) |
| النشر والويدجت | ويدجت المحادثة لموقعك |
| الرصيد والاستهلاك | استهلاك هذا الشهر بنظرة سريعة |
| إيقاف وتفعيل العروض | الردود التي يستلمها العملاء عند إيقاف العروض أو إعادة تفعيلها |
| العلامات | العلامات التي يضعها الموظفون على المحادثات |
| الردود الجاهزة | إجابات جاهزة مصنّفة، تُدرج بكتابة <kbd>/</kbd> |
| طوابير الانتظار | طوابير الانتظار في أوقات الضغط |
| الأسئلة الشائعة | أسئلة تجيب عنها كل البوتات |
| الذكاء الاصطناعي الصوتي | تحويل الرسائل الصوتية إلى نص ليفهمها البوت |
| مفاتيح API | مفاتيح لأنظمتك |
| سجل التدقيق | سجل للقراءة فقط لتغييرات الإعدادات المهمة |

## إيقاف العروض وتفعيلها

يتحكم العملاء بالرسائل **التسويقية** بأنفسهم، ولا تتأثر رسائل الخدمة.

- يوقف العميل العروض بالضغط على **إيقاف العروض** في قالب أو بكتابة كلمة إيقاف، فيستلم رد الإيقاف ويُستبعد من الحملات التسويقية بعدها.
- ويعيد التفعيل بكتابة كلمات مثل *start* أو *subscribe* أو *اشتراك* أو *تفعيل* (أو بالضغط على **قبول العروض**)، فيستلم رد التفعيل.

اكتب عدة ردود وحدّد الرد الفعّال (يظهر باللون الأخضر).

## الذكاء الاصطناعي الصوتي

فعّله لتحويل رسائل واتساب الصوتية إلى نص تلقائيًا وفهمها بالذكاء الاصطناعي، فيرد البوت كأن العميل كتب الرسالة. ويمكنك استخدام مفتاح مزوّد الذكاء الاصطناعي الخاص بك.

## السجلات

صفحة **السجلات** توثّق ما يحدث في مساحة العمل:

| السجل | ما يعرضه |
| --- | --- |
| النشاط | تسجيلات الدخول والأمان والوصول بين مساحات العمل |
| نشاط الموظفين | الإسناد والرد والإغلاق وانضمام الموظفين للمحادثات أو مغادرتها |
| الأحداث المخصّصة | الأحداث التي تطلقها عقدة *إطلاق حدث* في البوتات |
| إعادة المحاولات | محاولات إعادة إرسال الحملات، تلقائية أو يدوية |
| API | كل اتصال عبر التكاملات، مع إخفاء البيانات الحساسة |
| إجراءات الإدارة | تغييرات الباقة واعتماد الشحن وغيرها من إجراءات المسؤول على حسابك |
